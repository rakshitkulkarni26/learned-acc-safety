# Data

No dataset files are stored in this repository. Download scripts are added in Phase 1.

| Dataset | Access | Use in this project |
|---|---|---|
| NGSIM (US-101, I-80) | Public, US DOT via data.transportation.gov | Training data for the learned car-following policy |
| highD (German highways) | Free for non-commercial research after registration at highd-dataset.com | Cross-dataset evaluation |

highD terms prohibit redistributing the data or modified versions of it. Keep raw and processed files in this folder only; it is ignored by git.
